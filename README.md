# Dicasa - Projeto de Fundamentos de Construção de Páginas Web

Este projeto foi desenvolvido como parte das atividades da disciplina de Fundamentos de Construção de Páginas Web. O objetivo é demonstrar os conceitos básicos de desenvolvimento web utilizando HTML e CSS.

## Estrutura do Projeto

- `index.html`: Página principal do projeto
- `style.css`: Arquivo de estilos CSS
- `images/`: Diretório contendo as imagens utilizadas no projeto

## Tecnologias Utilizadas

- HTML5
- CSS3

## Como Visualizar o Projeto

1. Clone este repositório
2. Abra o arquivo `index.html` em seu navegador preferido

Ou acesse diretamente a página hospedada no GitHub Pages:
- [Di Casa Restaurante](https://veigagustavo.github.io/Dicasa/)

## Objetivos de Aprendizado

- Estruturação de páginas web com HTML
- Estilização com CSS
- Organização de arquivos e diretórios
- Boas práticas de desenvolvimento web
